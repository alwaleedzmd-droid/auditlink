# AuditLink - نظام المراجعة والسعودة

نظام ذكي لمراجعة الالتزام بنظام نطاقات وتحليل بيانات الموارد البشرية.

## المميزات
- تحليل بيانات GOSI والتأمين الطبي ونظام الرواتب
- محرك نطاقات لحساب نسب السعودة
- لوحة تحكم تفاعلية ببيانات حية
- تقارير قابلة للتصدير

## تشغيل المشروع محلياً

```bash
pip install -r requirements.txt
streamlit run app.py
```

## المتطلبات
- Python 3.8+
- المكتبات في `requirements.txt`
